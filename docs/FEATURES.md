# 功能说明

## 语言切换

- **F3** 或顶部「中/英」按钮切换；右键按钮可修改快捷键
- 切换只作用于显示层：输入框、编辑态文本、场景数据、表达式始终保留原文
- 切换后自动刷新可见菜单、参数面板、提示与帮助卡片

## 节点搜索（F4）

按 **F4** 打开检索面板；**Tab 保持 Houdini 原生菜单**，两者不冲突。

| 输入 | 命中 |
|---|---|
| `changfangti` / `长方体` | 长方体（Box） |
| `cft`（首字母） | 长方体 |
| `suxin` / `suxing` / `shuxing`（模糊音） | 属性 |
| `faxintie`（漏字母） | 法线贴图 |
| `uv贴图`、`box长方体`（中英混输） | UV 贴图 / 长方体 |
| `attr wrangle` | 属性处理 |

- 模糊音：`zh/z`、`ch/c`、`sh/s` 不分；`ang/an`、`eng/en`、`ing/in` 不分；`n/l` 不分
- 默认只列当前网络类别；无结果时自动到全部分类查找，并用 **Ctrl+L** 固定为全部分类
- 跨类别按 Enter 不会乱建节点，会提示应进入哪个网络
- 面板可拖动、可拉伸，大小记住；**Enter** 创建并关闭，**Shift+Enter** 连续创建

## 参数提示（help 覆盖层）

Houdini 的参数提示由帮助系统加载，用户偏好目录下的 `help/nodes/` 会覆盖安装目录
`nodes.zip` 里的同名文件。本插件据此在每个参数描述上方插入一行中文摘要：

```
Parameter: sizex                 ← 头部（引擎补丁：参数：sizex）
【盒子沿 X 轴的尺寸】              ← 中文摘要，单独成段
Size of the box along the X axis. ← 英文原文保留
```

- 覆盖 **2,787 / 4,729** 个节点，共约 **34,666** 条参数摘要
- 未命中的节点保持英文，不会出现半截中文或错行
- 标题与页脚由引擎钩子翻译（`Camera` → `相机`，`按 F1 查看帮助。`）
- `Parameter: %s` 头部由引擎补丁替换为 `参数：%s`，切回英文自动恢复
- 卸载：`python tools/build_help_overlay21.py --uninstall`，或删除
  `Documents\houdini21.0\help\nodes\`

> 修改覆盖层后需 **彻底退出并重启 Houdini**；如仍显示旧文本，
> 运行 `python tools/clear_help_cache21.py` 清理帮助缓存。

## 英文模式下的还原

引擎在翻译时记录「显示文本 → 原文」，切回英文时优先用这份会话缓存还原，
因此歧义译文（同一中文来自多个英文）也能精确还原，不会残留中文。

## 已知不覆盖

- Houdini 启动页（网页内容）
- 第三方 HDA、用户自定义端口、后续安装的 shelf 工具提示
- 节点图上与词典重名的名称可能显示译文（编辑框与数据保留原文）
