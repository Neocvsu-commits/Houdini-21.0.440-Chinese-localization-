## 三、只改这五个点（按性价比）

1. **长定语拆句**：`……的……的……系数` 改成「……时，……的系数」。对方 416 条差异长句里绝大多数是这种结构。
2. **术语定死三组**：纹理/贴图、三维/3D、对象/物体。挑一个，全库替换（你有统计脚本，见下）。
3. **中英空格**：12 处漏空格补上，对方 0 处。这 12 处其实是同一个模板复制出来的：
   `These keys apply to the XXX application.` → `这些按键适用于GReduce 应用…`（"适用于"后面漏空格），
   改一条模板就能全清。
4. **纠正语义错译**：`1/2/3 Float Default`、`Domain Error Value`、`Divide Error Value`。
5. **不要过度汉化**：VEX 函数名（Acos/Fit01/BD/FS）、参数内部名、单位符号保持原文。这条你本来就对，写进规范防回退。

**不建议做**：整体替换成对方的译文。19,509 条里我只挑出约 100 条是"明显更对"，
剩下的是风格取舍；整体替换会把你的术语体系和引号习惯一起冲掉。
