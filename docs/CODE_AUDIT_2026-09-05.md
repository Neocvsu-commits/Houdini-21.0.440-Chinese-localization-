# 本体代码审核与修复

基线：`eeedf9a`。范围：插件本体、显示入口、查词与缓存、安装生命周期、采集、
配置与按钮、构建和测试。保持纯显示层翻译，保留全部 79 个入口及原有安装优先顺序。

## 修复与规范化

| 问题 | 处理 |
|---|---|
| 缓存覆盖旧槽时，第二次字符串分配失败可能留下新原文与旧译文 | 两份独立副本都成功后再一次提交；测试注入两种分配失败 |
| 普通 Qt 临时布局只创建原行数，可能丢掉长译文末尾、丢失统一格式 | 和 Qt Quick 共用 `display_text_layout.h`；保留字体、统一格式、选项与位置；内容定宽布局可扩展，固定空间放不下时回退完整原文 |
| 部分测宽错误地测量完整译文，`horizontalAdvance("File", 0)` 也会变成非零 | 两个测宽入口保留源字符范围，整串测宽继续翻译 |
| 编辑保护在不同绘制入口不一致 | QTextLayout、QStaticText 使用设备级保护；可编辑 QGraphicsTextItem 同时保护其嵌套绘制 |
| 全进程模块扫描直接读取第三方映像头，坏模块可能异常或阻塞全轮补挂 | 提取安全身份读取；坏模块单独跳过，保留其旧状态，其他模块继续补挂 |
| 导入模块记录清理对每条记录遍历全模块列表 | 枚举基址构建哈希集合，包含暂时不可读模块，减少重复比较 |
| 虚表改写后恢复页保护失败被忽略 | 单独记录 `vtable_protection_restore` 错误，同时保留真实挂接状态及可调用原函数；不把已生效的 Hook 当成未安装 |
| 提示移除后仍保留快捷键字符串状态、每秒格式化，以及旧提示测试 | 删除这些无用途状态和操作，测试确认两个按钮无提示；保留按钮样式、位置和行为 |
| 英文模式下原生节点/视口仍先做 UTF-8 转换才判断关闭 | 未开启汉化且未开启显式采集时直接返回原参数 |
| 测试程序异常退出可能返回负数，`if errorlevel 1` 漏检 | 完整测试入口改为检查任何非零返回值；新增适配器测试指定匹配 SDK 的离屏 Qt 插件路径 |

没有删除节点、端口、材质树、视口的兜底路径。将重复临时布局代码提取到公共模块，
删除提示相关死状态及一个无用包含；未为减少代码行数拆除兼容路径。

## 后台开销

- 正常运行不启动未翻译词条采集、不保留其 32 MiB 文本区、不持续写采集文件。
- 调用诊断默认关闭；开启时只累计计数，报告由显式请求写出。
- 查词缓存为每线程 256 槽，原文和译文超过 4096 字符不保留；这是缓存容量，
  不是整个插件内存上限。
- 模块检查仍为启动前一分钟每 2 秒、之后每 15 秒。已成功扫描的同身份、
  同代模块不会重复改写导入表；头信息检查会继续进行以发现迟加载与卸载。
- 按钮保留每秒两次位置检查及每秒一次所有权检查；隐藏/最小化时跳过原生定位。
  当前没有实测证据支持删除这些用于跟随宿主布局的检查。

`tests/benchmark.bat` 可重复执行微基准，结果写入 `build/audit-runtime-benchmark.txt`。
本机 MSVC `/O2 /MD`、Qt 6.8.3、单线程、5 次中位数：

| 项目 | 结果 |
|---|---:|
| 缓存热命中 | 约 23 ns/次 |
| 缓存已知未命中 | 约 22 ns/次 |
| 诊断观察关闭 / 开启 | 约 0.4 / 5.2 ns/次 |
| 旧线性清理 / 新哈希清理（含集合建立、释放） | 约 292 / 40 μs/轮 |

清理基准使用相同的 1000 模块、79 个 Hook、每个 32 个存活导入模块。
这些只代表被测代码片段，不含完整绘制、字符串分类、驱动、宿主布局或系统调度成本，
不能换算成 Houdini 整体 CPU、帧率或启动时间改善。

## 验证与边界

本轮构建 `build/out-audit-review/package` 通过；完整 `tests/run.bat` 重跑通过，
其中 Python 25 项及新的实际显示适配器、离屏布局测试均明确输出通过。
`tests/analyze.bat` 完成，9 条警告来自 Windows/HDK 头文件，未报告项目源码问题。
测试平台插件路径失败后已修正并重新执行，未把那次异常退出算作通过。

新增真实显示适配器测试直接调用本体函数，使用可调用的原函数替身，验证部分测宽、
完整译文、编辑/选择/预编辑保护、原文不变及关闭时跳过原生转换。它不安装 Hook，
不驱动 Houdini 窗口。布局、分配失败、模块异常及虚表恢复失败均有单独回归测试。

构建目标仍为 Windows x64、Houdini 22.0.368、Qt 6.8.3。Qt 5 不兼容。
HDK API 标识与完整 Qt 版本校验继续保留；HDK API 标识不等于宿主完整日常构建号，
可能在多个 daily build 中相同。公开 ABI 检查通过不能证明私有布局和导出语义兼容。
目前未验证其他 Houdini 版本，也未声称跨版本运行兼容。

仍需手动检查节点与端口、材质库、透视/无相机、帮助卡、Qt Quick 面板、中英反复切换
和新窗口。复杂混合格式/源字符偏移无法安全映射时保留原布局；这是防止显示损坏，
并非已经实现所有富文本的完整翻译。不能保证任意新增渲染后端都已覆盖。

已知残余边界：非美式键盘布局的原生 `Shift+VK_OEM_3` 采集后备入口仍需对应布局实测；
轮询无法识别两次检查之间完全相同基址/大小/时间戳的卸载重载；操作系统拒绝恢复页保护时，
报告现在可识别问题，但不能保证强制恢复成功。没有修改正式安装包或自动提交本轮改动。
